When do check-ins open?

Check-ins are controlled by an admin in the admin dashboard. An admin must manually open check-ins for each event by clicking the "Open Check-in" button on the Event Check-ins page.

Once opened, students can scan their QR codes to check in. The admin can also close check-ins at any time.

Default state: checkinsOpen: false when imported. Admins must open them manually.
